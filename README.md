# NextGenTech Professional Multi-Page Website

Pages:
- index.html — Home
- about.html — About
- skills.html — Skills
- services.html — Services
- projects.html — Portfolio
- shop.html — Electronics Shop with search, category filters, local cart and WhatsApp checkout placeholder
- resume.html — Resume
- contact.html — Contact

## Important customization
1. Replace `your@email.com` and `+880 1XXXXXXXXX` with real details.
2. Add your CV as `assets/Maruf-CV.pdf`.
3. In `script.js`, replace `8801XXXXXXXXX` with your WhatsApp number (digits only, country code).
4. Replace demo electronics products/prices with your real inventory.
5. Replace emoji product visuals with real product images when available.
6. The contact form is a demo until connected to a backend/form service.

## GitHub Pages
Upload ALL files inside this folder to the repository root. Keep `index.html`, `style.css`, `script.js` in the root and keep the `assets` folder.
