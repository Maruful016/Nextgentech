# NextGenTech Personal Website

A premium dark, responsive personal/brand portfolio website.

## Files
- index.html
- style.css
- script.js
- assets/Maruf-CV.pdf (add your own CV here)

## Customize
1. Replace `your@email.com` with your real email.
2. Replace `+880 1XXXXXXXXX` with your WhatsApp number.
3. Put your CV at `assets/Maruf-CV.pdf`.
4. Replace project descriptions and links with your real projects.
5. Add your social links to the footer/contact section if needed.

## Run
Open `index.html` in any browser.

For publishing, upload the folder to GitHub Pages, Netlify or Vercel.
